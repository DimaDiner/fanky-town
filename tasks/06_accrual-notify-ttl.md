# Срок жизни в сообщениях о начислении

## Цель

Во всех сообщениях клиенту о начислении бонусов указано, сколько месяцев их можно использовать.

## Контекст

Сообщения: `notify_accrual` в `main.py` (массовое начисление из CRM); приветствие после регистрации в `bot/handlers.py` (web_app_data) и текст в `static/register.html`. Касса при **списании** шлёт `notify_customer` — его не трогать. При **начислении с кассы** сейчас уведомления нет — добавить `notify_accrual` с тем же текстом срока (природа начисления любая).

## Требования

1. Текст в духе: бонусы можно использовать в течение **N** месяцев (N из настройки на момент отправки).
2. Если TTL = 0 — **не** писать про срок (бессрочно), остальной текст начисления сохранить.
3. `notify_accrual(tg_id, amount, new_balance, ttl_months: int)` — передавать N явно из места вызова (не ходить в БД из sync httpx без сессии).
4. Русские формы: 1 месяц / 2 месяца / 5 месяцев.
5. Регистрация: в текстах бота и `register.html` тоже указать срок. Для HTML — значение с бэкенда (поле в ответе `POST /customers/` или GET настроек). Не хардкодить число месяцев в HTML.
6. Сторно `expiry` — без сообщений (задача 05).

## Затрагиваемые файлы

- `main.py` — `notify_accrual`, вызовы после accrue и кассового начисления
- `schemas.py` / ответ создания клиента — если нужно отдать `bonus_ttl_months`
- `bot/handlers.py` — текст приветственных бонусов
- `static/register.html` — текст после регистрации

## Критерии приёмки

- [ ] Сообщение массового начисления содержит срок при N>0
- [ ] Сообщение регистрации содержит срок при N>0
- [ ] При N=0 фразы про месяцы нет
- [ ] Начисление с кассы тоже уведомляет с тем же правилом
- [ ] Списание с кассы по-прежнему без текста про срок жизни

## Результат воркера
- **main.py** — `notify_accrual(tg_id, amount, new_balance, ttl_months)` с фразой про срок (склонение месяц/месяца/месяцев); при TTL=0 фраза не добавляется. Хелперы `_months_word` и `_ttl_phrase`. Массовое начисление и кассовое начисление (`amount > 0`) передают TTL из `get_bonus_ttl_months(db)`.
