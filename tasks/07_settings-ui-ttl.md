# Поле TTL бонусов в настройках CRM

## Цель

Администратор задаёт «Время жизни бонусов (месяцев)» на вкладке «Настройки».

## Контекст

Вкладка `#content-settings` в `static/admin.html`: блоки «Бонус за регистрацию» и «WhatsApp». Паттерн: input + Сохранить + статус. Доступ только у admin (вкладка и так скрыта у operator/booker).

## Требования

1. Карточка рядом с бонусом регистрации: заголовок **«Время жизни бонусов (месяцев)»**.
2. Пояснение: срок для **новых** начислений = момент начисления + это значение; смена настройки **не** меняет уже выданные партии; **0** — новые бонусы не сгорают. По умолчанию при первом запуске — **3** месяца.
3. Числовой input, кнопка «Сохранить», статус успех/ошибка — как у `registration_bonus`.
4. `loadSettings()` заполняет поле из `bonus_ttl_months`.
5. Сохранение: `PATCH /admin/settings/bonus_ttl_months` с телом `{ "value": "..." }`.
6. Валидация на клиенте: целое ≥ 0.

## Затрагиваемые файлы

- `static/admin.html` — разметка настроек, `loadSettings`, функция сохранения

## Критерии приёмки

- [ ] Поле видно на вкладке «Настройки» у admin
- [ ] Сохранённое значение переживает перезагрузку страницы
- [ ] Некорректный ввод не уходит на сервер / показывается ошибка
- [ ] Operator/booker по-прежнему не видят вкладку настроек
