# Обзор задач: герои, срок жизни бонусов, прошедшие брони

## Исходная задача

1. Расширить справочник героев бронирования (переименовать «Стач» → «Стич», добавить новых персонажей).
2. Единая настройка «Время жизни бонусов (месяцев)» в CRM (дефолт **3**). При релизе уже начисленные партии получают `expires_at = сейчас + настройка`. Дальше срок пишется только в момент нового начисления; смена настройки старые партии не двигает. По истечении — сторно без уведомления; в сообщении о начислении — срок действия.
3. В календаре бронирований визуально серым помечать уже прошедшие брони по текущей дате/времени.
